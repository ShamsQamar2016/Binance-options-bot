# Иш вақти — ходимлар келди-кетдисини ҳисоблаш

Ишхонадаги планшетда ходимлар «Келдим» / «Кетдим» тугмасини босади,
сизнинг Телеграмингизга дарҳол хабар келади. Кунлик ва ойлик иш соатлари
автоматик ҳисобланади.

## Нима қила олади
- Планшетда ҳар бир ходим учун катта «Келдим» ва «Кетдим» тугмалари (адашиб босмаслик учун «Ҳа / Йўқ» сўралади).
- Ҳар босишда Телеграмга хабар: ким, соат нечада келди/кетди, кечикдими, неча соат ишлади.
- Соат **09:30** да (созланади) «ҳали келмаганлар» рўйхати келади.
- Соат **20:00** да (созланади) кунлик ҳисобот, ой охирида ойлик ҳисобот келади.
- Бот буйруқлари:
  - `/bugun` — бугун ким келди, ким келмади, ким неча соат ишлади
  - `/kecha` — кечаги ҳисобот
  - `/kun 05.11.2026` — исталган кун
  - `/hafta` — шу ҳафта соатлари
  - `/oy` — шу ой соатлари (`/oy 2026-10` — бошқа ой)
  - `/excel` — ойлик жадвал файли (Excel'да очилади)

## Ўрнатиш (1 марта)

### 1. Телеграм бот яратиш
1. Телеграмда **@BotFather** ни очинг → `/newbot` → номини ёзинг.
2. У берган **token** ни (масалан `7123456789:AAH...`) сақлаб қўйинг.

### 2. Дастурни ишга тушириш
Компьютерга (ёки ишхонадаги доим ёқиқ турадиган компьютерга) **Python 3.9+** ўрнатинг (python.org).
Қўшимча кутубхона керак эмас.

```
cd ish_vaqti
copy config.example.json config.json     (Linux/Mac: cp config.example.json config.json)
```

`config.json` ни очиб, `bot_token` га токенни ёзинг. Кейин:

```
python app.py
```

### 3. Ўз chat ID ингизни қўшиш
Ботингизга Телеграмда `/start` юборинг — бот сизга **chat ID** рақамингизни юборади.
Уни `config.json` даги `admin_chat_ids` га ёзинг (бир неча киши бўлса: `[111, 222]`)
ва дастурни қайта ишга туширинг (Ctrl+C, кейин `python app.py`).

### 4. Планшетни улаш
Компьютер ва планшет битта Wi-Fi да бўлсин. Компьютер IP манзилини билинг
(Windows: `ipconfig` → IPv4, масалан `192.168.1.10`).
Планшет браузерида очинг: `http://192.168.1.10:8080`

Маслаҳат: браузерда «Бош экранга қўшиш» (Add to Home screen) қилинг ва
планшетни доим зарядда, экранни ўчмайдиган қилиб қўйинг.

## Созламалар (`config.json`)
| Майдон | Маъноси |
|---|---|
| `bot_token` | BotFather берган токен |
| `admin_chat_ids` | Хабар оладиган одамлар chat ID лари |
| `workers` | Ходимлар рўйхати — янги ходим қўшиш/ўчириш шу ерда |
| `port` | Веб-саҳифа порти (8080) |
| `utc_offset_hours` | Вақт зонаси (Тошкент = 5) |
| `work_start` | Иш бошланиш вақти — кечикишни ҳисоблаш учун |
| `absent_report_time` | «Ким келмади» хабари вақти |
| `daily_report_time` | Кунлик ҳисобот вақти |

Маълумотлар `ish_vaqti.db` файлида сақланади — уни ўчирманг, вақти-вақти билан нусха олиб қўйинг.
