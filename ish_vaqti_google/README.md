# Иш вақти — Телеграм бот + Google Таблица (серверсиз)

Компьютер ёқиб қўйиш шарт эмас — бот бепул Google серверида ишлайди,
маълумотлар Google Таблицага ёзилади.

## Қандай ишлайди

**Планшетда** Телеграм очиқ туради, пастда доим тугмалар:

```
[ ✅ Баходир келдим ]  [ 🏁 Баходир кетдим ]
[ ✅ Тулаган келдим ]  [ 🏁 Тулаган кетдим ]
[ ✅ Иброхим келдим ]  [ 🏁 Иброхим кетдим ]
[ ✅ Шавкат келдим  ]  [ 🏁 Шавкат кетдим  ]
```

**Сизга (раҳбарга)** келадиган хабарлар:

| Вақт | Хабар |
|---|---|
| Ҳар босишда | «✅ Баходир ишга келди — 08:55» / «🏁 … кетди, ишлади 9 соат 10 дақ» |
| 09:30 | Ҳали келмаганлар рўйхати |
| 19:00 | «Кетдим» босмаганлар — **[✅ 18:00 да кетган]** **[✏️ Бошқа вақт]** тугмалари билан |
| 20:00 | Кунлик ҳисобот |
| Ой охири | Ойлик ҳисобот + жадвал |

**Кунига бир марта:** «Келдим» ва «Кетдим» кунига бир мартадан ёзилади. Қайта босилса,
планшетда «сиз бугун 08:55 да келгансиз» чиқади, раҳбарга хабар бормайди.

**«Кетдим» эсдан чиқса:** сиз ҳеч нарса қилмасангиз, ўша кун **18:00 гача** ҳисобланади
ва ҳисоботда «⚠️ кетдим босилмаган» деб белгиланади. Эртасига ходим «Келдим»ни бемалол
босаверади.

**Раҳбар тугмалари:** 📋 Бугун · 📅 Кеча · 🗓 Ҳафта · 📊 Шу ой · ✏️ Тузатиш · 📑 Жадвал

**Тузатиш:**
- «✏️ Тузатиш» → кеча/бугунги ёзувлардан бирини танланг → келиш ёки кетиш вақтини ёзинг ёки ўчиринг.
- Бошқа кунлар учун:
  - `/tuzat Шавкат 05.11 08:50 18:00` — ўша кунни шу вақтлар билан ёзиш
  - `/tuzat Шавкат 05.11 келмади` — ўша кунни ўчириш
- Ёки тўғридан-тўғри Google Таблицадаги «Журнал» варағида ўзгартириш мумкин.

## Ўрнатиш (15 дақиқа, бир марта)

### 1. Бот яратиш
Телеграмда **@BotFather** → `/newbot` → номини ёзинг → берган **токен**ни нусхалаб олинг
(масалан `7123456789:AAH...`).

### 2. Google Таблица ва код
1. [sheets.google.com](https://sheets.google.com) да **янги бўш таблица** очинг (номи: «Иш вақти»).
2. Менюдан **Кенгайтмалар → Apps Script** (*Extensions → Apps Script*).
3. Очилган ойнадаги бор кодни ўчириб, **`Code.gs`** файлидаги бутун кодни қўйинг. 💾 Сақланг.
4. Юқоридаги рўйхатдан **`setup`** функциясини танлаб, **▶ Run** (Выполнить) босинг.
   Google рухсат сўрайди → аккаунтингизни танланг → *Advanced → Go to … (unsafe)* → *Allow*.
   (Бу ўзингизнинг кодингиз, хавфсиз.)
5. Таблицага қайтинг — «Созламалар», «Ходимлар», «Журнал» варақлари пайдо бўлади.
   «Созламалар»даги **BOT_TOKEN** қаторига токенни ёзинг.

### 3. Web app қилиб чиқариш
1. Apps Script'да **Deploy → New deployment** (Развернуть → Новое развертывание).
2. ⚙️ тури: **Web app**.
   - *Execute as*: **Me** (Мен)
   - *Who has access*: **Anyone** (Ҳамма)
3. **Deploy** → чиққан **Web app URL** (`…/exec` билан тугайди) ни нусхалаб, «Созламалар»даги
   **WEBAPP_URL** қаторига ёзинг.

### 4. Ботни улаш
Apps Script'да **`ulash`** функциясини танлаб **▶ Run** босинг.
Пастда «✅ Бот уланди: @…» чиқади.

### 4б. Cloudflare воситачиси (мажбурий)
Google Apps Script доим «302» жавоб қайтаради. Телеграм буни хато деб ҳисоблайди ва
хабарларни қайта-қайта юбориб, янгиларини навбатда ушлаб туради — бот «қотиб» қолади.
Бепул Cloudflare Worker шу муаммони ҳал қилади:

1. [dash.cloudflare.com](https://dash.cloudflare.com) да рўйхатдан ўтинг (email + парол).
2. **Workers & Pages** (ёки **Compute → Workers**) → **Create** → **Hello World** → номи `ish-vaqti` → **Deploy**.
3. **Edit code** → ичидагини ўчириб, **`cloudflare-worker.js`** кодини қўйинг.
   Биринчи қатордаги `GAS_URL` га «Созламалар»даги **WEBAPP_URL** ни (…/exec) қўйинг → **Deploy**.
4. Worker манзилини (`https://ish-vaqti.<номингиз>.workers.dev`) нусхалаб, «Созламалар»даги
   **RELAY_URL** қаторига ёзинг.
5. Apps Script'да **`ulash`** ни қайта ишга туширинг. Журналда «Cloudflare орқали: …» чиқади.
6. Текшириш: **`tekshir`** функциясини ишга туширинг — `pending_update_count: 0` бўлиши ва
   `last_error_message` бўлмаслиги керак.

### 5. Раҳбар ва планшет
1. **Ўз телефонингиздан** ботга `/start` ёзинг — сиз раҳбар бўласиз (биринчи ёзган одам).
2. **Планшетда** алоҳида Телеграм аккаунт билан ботга `/start` ёзинг.
3. Телефонингизга «📱 Янги қурилма…» хабари келади → **[✅ Планшет сифатида рухсат бериш]** ни босинг.
4. Планшетда тугмалар пайдо бўлади. Тайёр! 🎉

Планшет маслаҳати: доим зарядда турсин, экран ўчмайдиган қилиб қўйинг,
ботни Телеграмда «Закрепить» (pin) қилинг.

## Созламалар

«Созламалар» варағида ўзгартирилади — **қайта deploy керак эмас**:

| Созлама | Маъноси |
|---|---|
| `ISH_BOSHLANISH` | 09:00 — кечикиш шу вақтдан ҳисобланади |
| `ISH_TUGASH` | 18:00 — «Кетдим» босилмаса шу вақтгача ҳисобланади |
| `KELMAGANLAR_VAQTI` | 09:30 — «ким келмади» хабари |
| `ESLATMA_VAQTI` | 19:00 — «кетдим босилмади» эслатмаси |
| `KUNLIK_HISOBOT` | 20:00 — кунлик ҳисобот |
| `DAM_OLISH` | Якшанба — бу кунлари «келмади» хабари келмайди (`Шанба, Якшанба` деб ёзиш мумкин) |
| `ADMIN_IDS` | Хабар оладиганлар. Иккинчи раҳбар қўшиш: унинг ID сини вергул билан ёзинг |
| `PLANSHET_IDS` | Рухсат берилган планшетлар (бот ўзи ёзади) |
| `RELAY_URL` | Cloudflare Worker манзили — Телеграм шу манзилга уланади |

**Ходим қўшиш/ўчириш:** «Ходимлар» варағида исмни ёзинг ёки ўчиринг.
Кейин планшетда ботга `/start` ёзинг — тугмалар янгиланади.

## Муаммо бўлса
- **Бот жавоб бермаяпти:** `tekshir` ни ишга туширинг. `302` хатоси бўлса — RELAY_URL тўлдирилганини текширинг ва `ulash` ни қайта ишга туширинг. Apps Script → *Executions* бўлимида хатоларни кўриш мумкин.
- **Кодни ўзгартирдингиз:** Deploy → *Manage deployments* → ✏️ → *Version: New version* → Deploy.
  (URL ўзгармайди.)
- Хабарлар 1–3 сония кечикиб келиши мумкин — бу Google'нинг одатий ишлаши.
